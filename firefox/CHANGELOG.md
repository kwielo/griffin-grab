## 1.0.0 - 2026-11-16

- Copy the current page address with Control+Command+C on Mac, or Ctrl+Shift+U on other systems.
- Copy the same address from the toolbar icon.
- Right-click the toolbar icon to see the keyboard shortcut assigned on this computer.
- Follow the light or dark toolbar theme, and turn the icon green when the address was copied.
- Keep the address on this computer. The extension does not use the network.
